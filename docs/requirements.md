# Project Requirements

## Functional Requirements

1. Accept customer support ticket details.
2. Retrieve approved support knowledge.
3. Generate a support reply using Gemini.
4. Return a structured response.
5. Validate the generated output.
6. Require human review before final response.
7. Support Approve, Edit and Reject actions.
8. Handle unsupported or unavailable information safely.

## Non-Functional Requirements

- Simple REST API
- Clear error handling
- Grounded responses
- Human oversight
- Maintainable project structure
- Evaluation and testing evidence
